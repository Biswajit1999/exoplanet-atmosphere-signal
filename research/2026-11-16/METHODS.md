# Conditional CO template covariance audit — 16 November 2026

This independent module does **not** replace the released Grant et al. in/out-band contrast. It fits a supplied spectral template amplitude with generalized least squares and an optional nuisance intercept, and sweeps an **assumed** stationary AR(1) wavelength-bin correlation coefficient. It does not infer the actual covariance from the archived spectra.

The covariance is C_ij = sigma_i sigma_j rho^|i-j| with |rho|<1. Inverse Fisher information supplies a *conditional* amplitude standard error. Assumptions: Gaussian residuals, fixed template, fixed wavelength ordering, positive-definite supplied covariance, and no template-selection penalty. A nominal amplitude/error ratio is **not** a molecule-detection significance. Adjacent pixels need not obey stationary AR(1).

Run independently from this directory with `python -m pytest -q`. A standalone synthetic sensitivity plot can be regenerated by `python make_diagnostic.py`. The figure is illustrative, not observational. Source reference: Grant et al. 2023, doi:10.3847/2041-8213/acfc3b; archived data Zenodo 10.5281/zenodo.7866690. No upstream products are modified.
